# # # # 社区提示库

添加您最好的快捷键 — bot 自动合并有效的 PR. 浏览 [`prompts.md`] (prompts. md) 或以下分类 。

□ 贡献
1. 叉 = 编辑 `prompts.md` = 将您的提示加在正确的分类下
2. 开放PR → ** 自动合并** →
3. 快速格式:
```markdown
### [Name](link-to-author)
> The prompt text. Explain briefly what it does.
```

# # # # 启动类
- ** 编码** — 调试、 重构、 解释、 生成
- **写**——博客文章、文件、翻译
- ** 分析**——摘要、摘录、比较
- ** 代理人**——系统提示,人物设计
- **图像**——中途岛/SDXL快速食谱

直播列表参见`prompts.md`.
